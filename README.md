# 🏏 IPL Business Intelligence & Forecasting Dashboard

## 📌 Project Overview
End-to-end data analytics project analyzing 17 seasons of IPL data (2007-2025) using Python, SQL and Power BI to derive business insights and forecast future trends.

## 🛠️ Tech Stack
- **Python** — Data cleaning, EDA, Analysis
- **Pandas & NumPy** — Data manipulation
- **Matplotlib** — Data visualization
- **SQLite & SQL** — Database queries & window functions
- **Power BI** — Interactive dashboard

## 📊 Dataset
- 1,169 IPL matches across 17 seasons (2007-2025)
- 278,000+ ball by ball records
- 14 teams, multiple venues

## 🔍 Key Insights
- 🏆 Gujarat Titans have highest win rate (61.67%)
- 🎯 Toss winners lose 61.78% of matches
- 🏏 Virat Kohli leads all time run scorers (8,671 runs)
- 🎳 YS Chahal leads all time wicket takers (221 wickets)
- 📈 IPL scoring trend increasing — forecast 341 runs/match by 2028
- 🏃 Fielding first after winning toss wins more (40.93%)
